# Palms Footwear Store 🌴
## Premium E-commerce Platform - 2026 Project Structure

This project is built with **"Simple, Luxury & Clean Code"** principles, strictly using a pure **HTML, CSS, and JS** tech stack.

### 🏗️ File Architecture
The project follows a modular structure where the customer/user experience is contained within a dedicated `public` folder, reserving space for the upcoming `admin` dashboard.

```text
/Top Slides
├── /public             # All user/customer-facing files
│   ├── /css
│   │   └── main.css    # Premium minimalist design system
│   ├── /js
│   │   └── main.js    # Smooth scroll & interaction logic
│   ├── /assets
│   │   └── /images     # High-end footwear lifestyle imagery
│   └── index.html      # The finished Luxury Homepage
├── /admin              # Placeholder for future Admin Dashboard
├── Palms_PRD_2026.md   # Core product requirements
└── README.md           # This architecture guide
```

### ✨ Performance & Style
- **Luxury Feel**: Minimalist layout, generous whitespace, and premium typography (Outfit/Inter).
- **Speed Run Workflow**: Frictionless, guest-only checkout starts directly on the homepage.
- **Pure Tech**: No dependencies, `npm`, or build steps. Open `public/index.html` to view.

### 🛠️ Technology Choices
- **Relative Pathing**: Ensuring the project works flawlessly across any local file system or static hosting within the `/public` root.
- **Optimized CSS**: Custom variables for a consistent "Lagos Luxury" design system.
